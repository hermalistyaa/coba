
# Telkom University Company Profile - Praktikum
 
Project simulasi HTML, CSS, PHP native, MySQL/MariaDB, dan Git.

## Cara Menjalankan Project

1. Instal dan jalankan XAMPP.
2. Aktifkan Apache dan MySQL.
3. Letakkan folder project di direktori `htdocs`.
4. Impor database melalui phpMyAdmin jika diperlukan.
5. Buka browser dan akses `http://localhost/telkom-company-profile/`.

Lihat file konfigurasi `config/database.php` untuk memastikan koneksi database sudah sesuai.
